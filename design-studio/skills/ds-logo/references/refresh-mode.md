# Refresh Mode — part of the ds-logo skill

Read in full the moment the member's path is "I have a logo but it's not quite right".

## REFRESH MODE — EVOLVE AN EXISTING LOGO, DON'T REPLACE IT

For the leader who has used their logo for a year or two and sort-of likes it: the job is EVOLUTION.
Agents who have seen it on their content should think "oh, they cleaned it up" — never "who's that?"
Recognition is the whole point; the member's audience already knows this mark.

**The brief already told you the scope.** The Design Package brief says *"change only [the one thing
flagged]"* — that one thing (the font feels dated · the colours are off · it needs a small emblem · it
looks cheap · the spacing) is the entire scope. If the brief has no flagged item, ask the ONE
question: *"What's the one thing you'd change?"* and record only that.

**The refresh brief (replaces the from-scratch questions):**
- **Upload your current logo** — the best file they have (a transparent PNG or the original logo file — SVG, AI, or PDF — beats a
  screenshot; take whatever they've got; check `02 · Brand` first — if it's already there, use it).
- **What do you LIKE about it?** *(multi-select)* — the name treatment · the symbol · the colours ·
  the overall layout · the feeling of it. Everything they like is LOCKED.
- **What bugs you?** *(only if the brief didn't say)* — the font feels dated · the colours are off · it
  needs a small emblem · it looks cheap or clip-art · the spacing/proportions · "not sure — just make
  it better."
- **How far can I go?** *(default Moderate)* — Light touch (spacing, weights, colour polish — nothing
  structural) · Moderate (swap the font, refine the mark, keep the structure) · Bold but recognizable
  (new type + a refined mark, same core idea and layout).

**The refresh rules:**
- **Rebuild faithfully first, then improve.** An uploaded logo is usually a flattened image, so
  recreate it CLEANLY as a matching baseline (closest really-available fonts, exact colours) and then
  apply the improvements — and tell the member that's the process. The baseline must be honest: if a
  perfect font match isn't available, name the closest match you actually used.
- **Change ONLY what they flagged** (within the degree they chose). Never change the name's spelling
  or casing without asking. Never add a house or a key "while you're in there".
- **Present 3–4 EVOLUTION options, each as a BEFORE / AFTER pair** — their current logo beside the
  refreshed version — so the improvement is visible and the recognition is provable. Options differ in
  WHAT they touch (type-only refresh · colour-refined · same logo + a small new emblem · the full
  chosen-degree evolution) — never four unrelated new logos.
- **The recognition test replaces the distinctiveness test:** at a glance, is this obviously the SAME
  brand, upgraded? If a version reads as a brand-new logo, it's out of bounds — pull it back.
- **The brokerage check still applies:** if the member's current lead colour sits inside their
  brokerage's palette, say so once and offer the shift as one of the options — the leader brand stays
  visually distinct from the brokerage's own colours (it may be the very thing that "felt off").
- **The two-name rule still applies:** if the brief wants an organization version too, build it from
  the REFRESHED mark's construction language so the pair are siblings.
- After they pick one, everything else runs as normal: the full family in stages, the export page and
  file delivery (transparent PNG + SVG, dark and one-colour versions, the content header, favicon),
  the hand-off package, and the push to `02 · Brand`.

**The refresh craft moves (what "cleaned up" actually means — reach for these first):**
- **Sample, don't eyeball.** Pull the EXACT colours from the uploaded file for the baseline (from large
  solid areas, never anti-aliased edges). To modernize colour, shift WITHIN the same hue family — a
  harsh saturated blue becomes a deeper, slightly muted navy — so it reads as the same brand in better
  clothes. Never jump hue families unless the member flagged the colours or the brokerage check demands it.
- **Fix the spacing first.** Even out the letter-spacing, sit the mark and name on a shared baseline
  or centreline, and equalize the margins. Spacing repairs alone make a logo look years newer, and
  they're always inside even a "Light touch".
- **Harmonize stroke weights.** A mark drawn in three different line thicknesses reads homemade —
  redraw it to one or two consistent weights that match the type's weight.
- **Know the dated-font tells and their modern swaps:** stiff "computer cursive" → a real flowing
  signature script; hand-drawn/novelty faces → a clean humanist sans; engraved wide-tracked caps → a
  modern high-contrast serif; default system bold → a designed geometric or grotesk. Name the actual
  swap you made in the details line so the upgrade is visible.
- **Retire the listing cue, if they asked.** When the one flagged thing is "it looks like a realtor
  logo, not a leader's", the move is to replace the house/roofline with a constructed monogram or an
  idea emblem that keeps the SAME colours, type, and layout — the audience still recognizes it.

STEP 2–4 of the main skill are the FROM-SCRATCH path; the craft, text rules, descriptor rules,
language, and compliance sections apply to BOTH paths.
