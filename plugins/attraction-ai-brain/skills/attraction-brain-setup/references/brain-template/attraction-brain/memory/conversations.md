# Conversations — every agent conversation, dated
*memory · the AI's working memory of what was said, NOT the CRM*
*Owner: the Conversion & Sales plugin (Week 5) — its logging skills `cv-conversation-starter`, `cv-dm-flow`, `cv-debrief`, `cv-follow-up`, `cv-three-way`, `sales-show-up` (a no-show), `sales-scorecard` (a missed call); `cv-objection-coach` fills only the `Objection heard` cell of today's row. Interim writers before it is installed, same shape: `attraction-capture` (on the go — and it keeps appending after, when the member captures), `sf-comment-to-dm` (a conversation that starts from a Reel or story — through `attraction-capture` when the Brain plugin is present, directly otherwise). The Debrief logs the day's conversations inside its own entry and never writes this file. Readers: AI Admin, Events, the Debrief, Short-Form (read-only), `attraction-top-50` (the newest row per name = Last touch, once the Admin exists).*
*`Stage after` is the durable stage REQUEST once the AI Admin is installed: the writer fills that cell, ends its output with `STAGE MOVE REQUESTED: [Name]: [from] → [to]`, and `admin-pipeline` applies it; before the Admin exists the same writers move `memory/pipeline.md` directly. A dated `Next step` is the durable carrier of `NEXT MOVE REQUESTED: [Name]: [move] · due [date]` (no stage change).*
*Append-only. Never rewrite history. Names and notes here are the member's private data.*
