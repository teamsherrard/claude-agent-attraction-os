# Pipeline — where every prospect agent stands
*memory · one vocabulary, every plugin · `admin-pipeline` (AI Admin, Week 5) is the sole writer once the Admin's `## AI Admin` block is in `config.md` — the source of stage OS-wide (`attraction-top-50` mirrors Stage, Next move, and Due from this Board). Until then `attraction-capture` and the Conversion logging skills write the Board row and a Stage-moves-log row directly (`Logged by: capture` / `cv-<skill>`), same words; the Debrief only requests moves.*
*Requests, once the Admin exists (it applies, never guesses): the `Stage after` cell of a `conversations.md` row + the chat line `STAGE MOVE REQUESTED: [Name]: [from] → [to]` · the Debrief's `Stage moves requested:` line (Events requests event stages the same way) · `NEXT MOVE REQUESTED: [Name]: [move] · due [date]` for a next move with no stage change. A scheduled run never writes this file. **A no-show never moves a stage backwards**: the agent stays at `Call booked`, `Next move` carries a `no-show [date]` note and the recovery step from the member's show-up sequence, `Due` is that step; a second no-show is the member's call — one more reschedule, or `Parked` with the why. Any move backwards is put to the member as one question, never applied.*
*Stages (locked, OS-wide): Identified → Conversation → Call booked → Call held → 3-way → Joined → Onboarded → Active. Parked = fit or timing, never disrespect.*
