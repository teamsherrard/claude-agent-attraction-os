# Host and moderator checklist — written for someone who wasn't in the room

*Mike's workshop-ops Phase 4 (event operations: "host/moderator/coach instructions → dependencies, bottlenecks,
risks, missing assets") and the delegation principle ("every system must be operable by someone who wasn't in
the room"). `ev-runofshow` fills this for each event; timings follow the playbook's shape.*

## Who does what
| Role | Who (from organization.md / operations.md, confirmed by the member) | Owns |
|---|---|---|
| Host | the member | the open, the teaching, the close, staying at the front afterwards |
| Co-host / speaker | [name] | their beat; the overflow conversations (live); the Q&A relay |
| Chat moderator (virtual) / door (live) | [VA or an agent] | pins the link; welcomes; runs the chat prompts; collects questions; notes who engaged (in the member's tool, never the Brain); name tags and sign-in (live) |
| Timekeeper | [co-host or VA] | the minute table; the "2 minutes" signal |
| Tech | [VA] | Zoom settings, recording, screen share, the backup phone hotspot; A/V and the clicker (live) |
| Follow-up owner | [VA or the member] | the attendance export the morning after; the replay link; the day-1 drafts loaded |
| Photographer (live) | [agent] | the photo spot; the room shots; the speakers' photos — consent for anyone quoted |
| Table hosts (live) | each agent in the organization | their invited guests + two strangers: seat, name, an introduction to the member |

|---|---|---|

| −30 min | dry run of the first two minutes; the moderator has the prompt list and the Q&A doc | host + moderator |
| −5 min | doors open: welcome slide, music low, the moderator greets by first name as people arrive | moderator |
| 0 | the host opens with energy; the moderator pins "drop where you're joining from" | host · moderator |

| the Q&A | the moderator reads questions in order received; the three pre-loaded ones if the chat is quiet | moderator · host |

## The chat moderator's script (virtual)
- Welcome by first name as people land ("Welcome, Priya — where are you joining from?").
- Pin the agenda line at 0, the booking link at the close, the resource link at the end.
- Run each prompt exactly when the outline says; repeat it once if the chat is quiet; never answer a teaching
  question in chat — "great one, saving it for the Q&A."
- Logistics only in chat ("the replay comes tomorrow by email").
- Note who engaged: answered a prompt · asked a question · stayed to the end · typed "link" at the close. That
  list is the hot list; it lives in the member's tool.
- Never pitch, never mention the brokerage, never answer a compensation question — "that's a question for
  [member] on a call; drop 'link' and I'll send the booking page."

## If it breaks
- Zoom drops → the backup hotspot; the moderator posts "rejoin with the same link" in the confirmation thread.
- Slides fail → the host teaches from the outline; the template is shared by link.
- A heckler or a competing-brokerage pitch in the chat → the moderator removes the message, says nothing
  negative, and the host carries on (the cardinal rules apply to the room too).
- Low turnout → the host runs the same show for the people who came; the recording is the asset.
- A compensation question from the room → "that's a private conversation — book a call and I'll walk you
  through it from the actual plan documents."
