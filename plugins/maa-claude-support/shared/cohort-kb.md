## The program

- **Name:** Master Agent Attraction (MAA) — "the Agent Attraction Cohort" in member-facing copy.
  The system members install is the **Agent Attraction OS**. (Mike's other program, the Social
  Agent OS / "the $10MM Short-Form Cohort", is a DIFFERENT cohort with a different plugin set —
  a member may be in both; see `stack-map.md` for how the two stacks coexist.)
- **Shape:** 6 weeks, fixed Tuesday starts, plus a bonus Week 7 for fast-action buyers.
- **Who:** real estate agents who have done deals and want residual income through agent
  attraction at a cloud-based brokerage (eXp, REAL, LPT, Epique, or any other) — or a local team
  or brokerage. Brokerage-agnostic; never assume eXp.
- **The order (the Agent Attraction Framework):** Positioning → Content → Conversation →
  Conversion → Retention → Duplication. Taught in Week 1, built over 6 weeks. Brain and
  positioning first, then the content engines (short then long form), then conversion, then the
  organization.
- **What's included:** 17 new core videos (2–3 per week) + 5 setup videos + the full MAA vault
  (101 recycled recorded lessons, ~11 hours) released weekly in Circle · 12 live Q&A calls ·
  6 playbooks + 7 bonus assets · the Agent Attraction OS (9 Cowork plugins + the Design Studio
  skill set + scheduled agents) · the Circle community for the 6 weeks, then Attraction OS
  continuity · ascension at graduation (the paid deep short/long-form course + a January-cohort
  credit worth 50% of the MAA investment).
- **The stack members install:** Plugin 1 (`attraction-ai-brain`) FIRST, then Plugin 2
  (`maa-claude-support`, this plugin), then each week's plugins as that week opens — see
  `stack-map.md`. The Design Studio is a Claude Design SKILL SET (uploaded zips), not a plugin.
- **About 2 hours of video a week** by design — members build instead of binge.
