# MAA lesson knowledge base — index (the Ask-Mike entry point)

Read THIS file first for any "what did Mike say about…" ask; then open only the one or two module
files that match (`${CLAUDE_PLUGIN_ROOT}/shared/kb/<module-slug>.md`). Never read the whole folder.
Every answer names the lesson title and hands the Loom link to rewatch. Built from
`knowledge/transcripts/manifest.md` (2026-10-08); lesson numbers are Mike's vault numbers, not row
counts. Module files are written by the doctrine agents from the transcripts and cite
`module/lesson`.

Numbering notes: lesson numbers are Mike's vault numbers and are NOT contiguous — there is no lesson 20, 45, 47, or 51; don't infer a missing lesson from a gap. Two lessons exist only as stub cards with no transcript (`01-foundation-mindset/4`, `03-model-positioning/12`): for those, name the title and hand the Loom — never quote or paraphrase content. `08-youtube/93` is a draft transcript. Bonus lessons cite as `bonus/<slug>`.

Cue rule: the "ask this when…" column is inferred from the lesson title — match the member's words
to a cue, confirm with the title, and let the module file (not this index) supply the substance.
